# 末日突围 · ZOMBIE SIEGE

第一人称视角的末日丧尸生存射击小游戏。你被困在丧尸围城的废墟中，必须消灭 6 波尸潮，完成突围。

纯 HTML5 + Canvas 2D 实现，**无任何第三方依赖、无音频资源文件**。场景与音效程序化生成，第一视角武器使用一张透明 PNG 素材，双击 `index.html` 即可游玩。

## 运行方式

方式一：直接用浏览器打开 `index.html`。

方式二：启动本地静态服务器：

```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 武器系统

匕首是默认武器，永远不会没弹药；其余武器通过**空投补给**与**击杀掉落**获得。

| 武器 | 类型 | 数值 | 说明 |
| --- | --- | --- | --- |
| 🔪 战术匕首（默认） | 近战挥砍 | 伤害 50 · 攻速 0.38s · 范围 2.3m | 60° 扇形可同时命中多只丧尸，无弹药限制 |
| 🔫 M4A1 步枪 | 全自动 | 30 伤害 · 爆头 ×3 · 弹匣 30 | 图片级第一视角模型，抛壳/枪口焰/连发后坐 |
| 💥 霰弹枪 | 泵动 | 8 弹丸 × 14 · 近距 112+ · 弹匣 6 | 距离衰减，贴脸一发清群，泵动拉栓动画 |
| 🧨 破片手雷 | 投掷物 | 引信 1.7s · 半径 4.6m · 中心 150 | 抛物线弹地反弹，接触丧尸即爆，**会误伤自己**（上限 5） |
| 🚀 火箭筒 | 直射爆破 | 半径 5.2m · 中心 210 · 弹速 26m/s | 触体/落地即爆，烟雾尾迹，贴脸自爆风险高（上限 3） |

- **每次开局首杀必定掉落一把远程武器**（M4A1 或霰弹枪），保证近战开局也能快速拿到枪
- 拾取新武器时自动切换并播放专属音效；已有武器再拾取则转化为对应弹药
- 投掷物用完后会自动切回最优武器；切枪有 0.24s 收放动画
- 没有远程武器或远程弹药全部耗尽时，空投会优先送来武器/弹药

## 玩法

- 共 **6 波**尸潮，每波清空后恢复 **25 生命 + 弹药补给**，通关第 6 波即突围成功
- **爆头额外伤害**：步枪 ×3、霰弹 ×2
- 游戏中每隔约 **9–16 秒**在玩家周围随机投放补给（弹药/医疗/武器），地面常规补给最多保留 3 个
- 弹药完全耗尽且场上没有补给时，系统会在 **2 秒内**保底投放，避免战斗死锁
- 击倒丧尸有 **30% 概率**掉落补给（弹药/医疗/手雷/武器，含稀有火箭筒）
- 爆炸会对范围内所有丧尸造成衰减伤害与击退，波次结束前飞行的手雷也会结算
- 三种丧尸：
  - 🧟 普通丧尸 —— 跛行逼近
  - 🏃 迅捷丧尸 —— 第 2 波起出现，高速低血量
  - 💪 狂暴丧尸 —— 第 4 波起出现，高血量高伤害（试试火箭筒）

## 技术要点

- **伪 3D 透视投影**：yaw/pitch 相机模型 + 深度排序的 billboard 渲染，Canvas 2D 实现
- **Pointer Lock API**：第一视角瞄准，支持 Esc 暂停与重新锁定
- **混合渲染**：丧尸、废墟建筑、粒子与 HUD 由 Canvas 程序化绘制；M4A1 使用带透明通道的写实第一视角素材，匕首/霰弹枪/手雷/火箭筒为程序化视图模型
- **多武器战斗**：近战扇形判定、全自动 hitscan、多弹丸散射、抛物线投掷物（弹地反弹+引信+触体引爆）、直射火箭（尾迹+触爆），统一爆炸系统（火球/冲击波环/火花/焦痕/自伤）
- **多层武器反馈**：枪身后坐、抛壳（步枪弹壳/霰弹红壳）、枪烟、方向性枪口火焰、镜头震动、动态准星、换弹位移与切枪收放动画
- **Web Audio API 程序化声景**：持续风声和低频氛围、脚步、分层枪声（步枪/霰弹/发射/爆炸）、机械换弹与泵动、挥刀与近战命中、丧尸低吼、受击与补给/拾取武器反馈均实时合成，无音频文件
- **游戏循环**：约 60fps 固定步长循环（`setInterval`，16ms），带时间步长钳制
- **Hitscan 命中判定**：准星射线与丧尸包围盒求交，按命中高度区分爆头/躯干

## 起源

本项目由 DeepSeek Harness 动态 Cordis 插件（`zomfps-1`）迁移而来：
插件版运行在对话页面内（启动面板 + 全屏浮层），本仓库为**独立可运行版本**，
界面由 React 改写为原生 DOM，Cordis timer 服务替换为 `setInterval`，其余游戏逻辑保持一致。
