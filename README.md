# 末日突围 · ZOMBIE SIEGE

第一人称视角的末日丧尸生存射击小游戏。你被困在丧尸围城的废墟中，必须消灭 6 波尸潮，完成突围。

纯 HTML5 + Canvas 2D 实现，**无任何第三方依赖、无图片/音频资源文件**（丧尸、城市、音效全部程序化生成），双击 `index.html` 即可游玩。

## 运行方式

方式一：直接用浏览器打开 `index.html`。

方式二：启动本地静态服务器：

```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 玩法

- 共 **6 波**尸潮，每波清空后恢复 **25 生命 + 30 弹药**，通关第 6 波即突围成功
- **爆头 3 倍伤害**：普通丧尸 1 枪爆头、2 枪躯干
- 击倒丧尸有 **24% 概率**掉落弹药箱（+18 弹药）或医疗包（+30 生命）
- 三种丧尸：
  - 🧟 普通丧尸 —— 跛行逼近
  - 🏃 迅捷丧尸 —— 第 2 波起出现，高速低血量
  - 💪 狂暴丧尸 —— 第 4 波起出现，高血量高伤害

## 技术要点

- **伪 3D 透视投影**：yaw/pitch 相机模型 + 深度排序的 billboard 渲染，Canvas 2D 实现
- **Pointer Lock API**：第一视角瞄准，支持 Esc 暂停与重新锁定
- **全程序化绘制**：丧尸造型（驼背、前伸利爪、发光眼、裂口獠牙、血迹伤口）、废墟城市剪影、粒子与 HUD 均为矢量绘制，无任何图片资源
- **Web Audio API 程序化音效**：枪声、丧尸低吼、受击、补给等由振荡器/噪声合成，无音频文件
- **游戏循环**：约 60fps 固定步长循环（`setInterval`，16ms），带时间步长钳制
- **Hitscan 命中判定**：准星射线与丧尸包围盒求交，按命中高度区分爆头/躯干

## 起源

本项目由 DeepSeek Harness 动态 Cordis 插件（`zomfps-1`）迁移而来：
插件版运行在对话页面内（启动面板 + 全屏浮层），本仓库为**独立可运行版本**，
界面由 React 改写为原生 DOM，Cordis timer 服务替换为 `setInterval`，其余游戏逻辑保持一致。
